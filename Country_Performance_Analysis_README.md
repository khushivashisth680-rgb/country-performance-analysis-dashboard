# Country Performance Analysis Dashboard

## Project Overview
An Excel-based country performance analysis project designed to analyze and compare countries across multiple indicators and present the results through a consolidated dashboard.

## Workbook Structure
- Dashboard
- Raw Data
- Total Score
- C Analysis
- E Analysis
- P Analysis
- S Analysis
- X1 Analysis & Final Analysis

## Analysis Performed
- Organized and analyzed raw country-level indicator data.
- Used Excel formulas such as AVERAGE, COUNTIF, MAX and MIN for summary analysis.
- Compared country performance across C, E, P, S and X indicators.
- Developed Total Score and Top 10 country analysis.
- Consolidated indicator-wise analysis into a final analysis.
- Created charts and a dashboard for data visualization.

## Excel Skills Demonstrated
- Data organization and analysis
- Statistical summary using Excel formulas
- Indicator-wise analysis
- Top 10/ranking analysis
- Data visualization
- Dashboard creation

## Key Deliverable
The main deliverable is the `Country_Performance_Analysis_Dashboard.xlsx` workbook containing the complete analysis and dashboard.
